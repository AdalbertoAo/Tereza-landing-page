# Tereza - Landing Page

**Tereza** é uma landing page moderna e otimizada, projetada para a apresentação de um produto digital voltado para o mercado de marketing. A página foi desenvolvida com foco em performance, responsividade e uma experiência de usuário fluida.

> [**Visite a página online**](https://tereza-landing-page.vercel.app/)

---

## Tecnologias Utilizadas

- **Astro**: Framework para construção de sites rápidos e estáticos.
- **TypeScript**: Linguagem com tipagem estática para maior segurança no desenvolvimento.
- **JavaScript**: Para funcionalidades dinâmicas e interatividade.
- **Tailwind CSS**: Framework CSS utilitário para estilização e design responsivo.
- **ShadCN (React Components)**: Conjunto de componentes prontos em React para uma interface de usuário moderna e eficiente.

---

## Funcionalidades

- **Design Responsivo**: A página se adapta perfeitamente a diferentes dispositivos e tamanhos de tela.
- **Animações Suaves**: Transições e interações fluídas para uma melhor experiência do usuário.
- **Formulário de Contato**: Formulário simples e funcional para interação direta com os visitantes.
- **Carregamento Rápido**: Aproveitando a geração de sites estáticos, o tempo de carregamento é otimizado para maior performance.

---
